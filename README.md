# Arise — Desperte. Evolua. Conquiste.

Aplicativo pessoal com controle financeiro, missões de XP e calistenia sem equipamentos.

## Instalação

- Abra `index.html` no navegador para testar.
- Para instalar como PWA e usar cache/offline, publique a pasta em um servidor HTTPS.
- Os dados são salvos localmente no navegador. Exporte backups regularmente.

## XP e níveis

- As atividades concluídas concedem XP automaticamente.
- A cada 100 XP conquistados, o jogador avança um nível.
- O cartão de nível mostra o rank, a barra de progresso e quanto falta para o próximo nível.
